🔄 State Management (Zustand)

Auth Store, UI Store (Toast, Modal) - Persistent Storage 통합

Auth Store

Features:

  • ✓ 로그인 상태 관리
  • ✓ 사용자 프로필 (Creator/Merchant)
  • ✓ JWT 토큰 관리
  • ✓ OAuth Provider 추적
  • ✓ Guest 모드 지원
  • ✓ localStorage 자동 저장
const { login, logout, user } = useAuthStore();

Toast Notifications

toast.success('메시지', '제목', 3000);

Modal System
